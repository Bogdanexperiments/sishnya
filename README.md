# СишнЯ

**Язык программирования:** C

**Назначение:** Лабораторные работы, учебные программы, алгоритмы и самостоятельные проекты на C.

> СишнЯ любит точные инструкции сборки: компилятор юмор не понимает.

## Структура каталогов

```text
Labs/
Projects/<project>/src/
Projects/<project>/include/
Projects/<project>/README.md
Experiments/
Documentation/
```

Реальные файлы лабораторных и проектов добавляются в соответствующие каталоги. Для нескольких C-программ, Python-скриптов или веб-сайтов заводи отдельную папку проекта.

## Запуск и сборка

Каждый отдельный проект хранится в `Projects/<project>/` и содержит собственные исходники и инструкцию сборки.
```sh
cd Projects/<project>
cc -std=c11 -Wall -Wextra -Wpedantic -O2 -Iinclude src/main.c -o app
./app
```
Для лабораторной работы используй её собственную команду сборки; не складывай несколько программ с разными `main` в одну команду.

## Учебные работы и проекты

Пока реальные работы в репозитории не добавлены. По мере готовности указывай здесь название, краткую цель и ссылку на папку каждой работы или проекта. Демонстрационные заглушки не используются.

## Будущие дополнения

Добавляй новые лабораторные работы и самостоятельные проекты в соответствующие каталоги. Для каждого самостоятельного проекта сохраняй локальные инструкции по запуску, сборке и зависимостям.
